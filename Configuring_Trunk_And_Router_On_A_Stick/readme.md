In this lab, I configured a **trunk link** between the switches and implemented a **Router-on-a-Stick** topology to enable inter-VLAN routing.
This involved creating **router subinterfaces** and configuring **802.1Q encapsulation** for each VLAN.
Network connectivity can be verified using the `ping` command to the corresponding IP addresses.
