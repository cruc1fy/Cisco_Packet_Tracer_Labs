In this lab, I implemented **Legacy Inter-VLAN Routing** by connecting the router to the switch using separate physical links for each VLAN.
Each router interface was configured with a **specific IP address** to serve as the default gateway for its respective VLAN.
Network connectivity can be verified using the `ping` command to the corresponding IP addresses.
